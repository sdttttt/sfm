# Sfm 网络上下行显示 — 实施计划（修订：端口范围可勾选）

## 结论先行

基于 sysinfo 0.39.6 的 `network` feature（`Networks` / `NetworkData`）新增网速采样。已从本机 sysinfo 源码确认两个关键行为，方案直接建立在其上：

1. `NetworkData::received()/transmitted()` 返回**距上次 refresh 的字节差**（新发现的接口首帧 `old == current`，差值为 0）——所以速率 = 字节差 ÷ 真实间隔，间隔需在 `Sampler` 里用 `std::time::Instant` 自己记录（刷新间隔可被用户改成 1/2/5 秒，还有「立即刷新」等不规则触发，不能用配置值估算）。
2. macOS 虚拟接口多（lo0/utun*/bridge*/awdl0…），统计范围**不写死**：菜单新增「端口范围」子菜单，逐个网卡接口勾选，**默认勾选全部 en\* 物理接口**，其余（回环、VPN 隧道等）默认不勾但可手动勾上。

UI 沿用已确认的方向：**状态栏标题 + 下拉菜单行都显示**，并带**「网速显示」持久化开关**（默认显示）；叠加本次新增的**「端口范围」子菜单**（持久化，默认全选 en\*）。

> 已知取舍：接口列表在启动时采集一次（VPN 连接后新出现的 utun 需重启 app 才会出现在子菜单里）。运行中动态重建 NSMenu 有菜单打开时的状态风险，v1 不做；持久化里保存的是接口名集合，重启后自动恢复。

## 2. 采样层（`src/metrics/net.rs` 新建，`src/metrics/mod.rs`）

`net.rs` 仿照 `cpu.rs`/`mem.rs` 的自由函数风格：

```rust
//! 网络上下行速率采样，基于 `sysinfo`。

/// 「默认勾选」用的判定：物理网卡（en + 纯数字后缀）。
/// 仅决定首次启动时哪些接口被勾上；之后的统计范围完全以持久化的勾选集合为准。
pub(crate) fn is_default_enabled(name: &str) -> bool {
    name.starts_with("en") && name[2..].bytes().all(|b| b.is_ascii_digit())
}

/// 刷新全部网卡的计数器。
pub(crate) fn refresh(networks: &mut Networks) {
    networks.refresh(true); // 传 true：已消失的接口（如断开的 VPN 隧道）从列表移除
}

/// 当前可见的全部接口名，排序后返回（菜单展示与自检都要求稳定顺序）。
pub(crate) fn interface_names(networks: &mut Networks) -> Vec<String>;

/// 勾选集合内接口「距上次刷新」的字节差之和（速率换算在 Sampler 里做）。
pub(crate) fn received(networks: &Networks, enabled: &HashSet<String>) -> u64;
pub(crate) fn transmitted(networks: &Networks, enabled: &HashSet<String>) -> u64;
```

`mod.rs` 改动：

- `Snapshot` 增加 `net_rx: u64`（下行字节/秒）、`net_tx: u64`（上行字节/秒），文档注明首次刷新为 0。
- `Sampler` 增加三个字段：`networks: Networks`（跨 tick 存活）、`net_window: Option<Instant>`（真实采样间隔）、`net_ifaces: HashSet<String>`（勾选集合，采样配置放采样层）。
- `Sampler` 新增方法：
  - `net_interface_names(&mut self) -> Vec<String>`：刷新一次接口列表并返回排序后的全部接口名。`main()` 在装配菜单前调用它采集列表（同时也顺带把 sysinfo 的基线置零）。
  - `set_net_ifaces(&mut self, HashSet<String>)`：供菜单勾选切换时更新。
  - `net_ifaces(&self) -> &HashSet<String>`：菜单读取当前勾选状态。
- `Sampler::refresh()`：`net::refresh` → 按勾选集求字节差 → `elapsed = self.net_window.replace(Instant::now())` → `None`（首帧）报 0，`Some(t)` 时 `rate = (delta as f64 / t.elapsed().as_secs_f64().max(0.05)).round() as u64`。下限 0.05s 防止连续「立即刷新」时除零、读数爆炸。

## 3. 格式化层（`src/format.rs`，与上一版一致）

- 新增 `pub fn format_rate(bytes_per_sec: u64) -> String`：复用 `format_bytes` 的档位（K/M 取整、G 一位小数），再右对齐到 **5 字符宽**（`"  0K"`、`" 340K"`、`"1023M"`、`" 1.0G"`）——延续百分比定宽防抖的哲学。
- `status_title` 签名追加末位参数 `net: Option<(u64, u64)>`：`None` 输出与现状完全一致；`Some((rx, tx))` 追加 `" ↓ 340K ↑1.2M"` 段。
- 新增 `pub fn net_row(rx, tx) -> String` → `"网速 ↓ 340K/s ↑1.2M/s"`。
- 测试：`format_rate` 边界、`net_row`、带网速段标题的宽度稳定性、现有 title 测试机械地补 `None`。

## 4. 偏好层（`src/prefs.rs`）

- key `net_shown`：`pub fn net_shown() -> bool`（键不存在时默认 `true`）；`set_net_shown(bool)`。
- key `net_ifaces`：持久化为逗号拼接的接口名字符串（如 `"en0,en5"`；接口名不含逗号，天然安全）。`pub fn net_ifaces() -> Option<Vec<String>>`（键不存在返回 `None`，由调用方套用 en\* 默认规则）；`pub fn set_net_ifaces(&[String])`。

## 5. 菜单层（`src/menu.rs`）

- `MenuParts` 增加：
  - `net: Retained<NSMenuItem>`（网速信息行，Swap 行之后）；
  - `net_shown: Vec<(bool, Retained<NSMenuItem>)>`（「网速显示」子菜单的 显示/隐藏 两项）；
  - `net_ifaces: Vec<(String, Retained<NSMenuItem>)>`（「端口范围」子菜单的接口勾选项，顺序与 `net_interface_names()` 一致）。
- `build()` 追加参数：`net_shown: bool`、`net_ifaces: &[String]`、`net_enabled: &HashSet<String>`。
- 「端口范围」子菜单（与「刷新间隔」「内存显示」「网速显示」平级）：每个接口一项，标题即接口名，selector 统一为 `toggleNetIface:`，**用 `setTag(下标)` 标识是哪一项**（接口名是运行时数据，没法像 MemStyle 那样为每个值编译期各配一个 selector），按勾选集合设置初始勾选态。
- 「网速显示」子菜单：仿「内存显示」，`setNetShownOn:` / `setNetShownOff:`。

## 6. 应用层（`src/main.rs`）

- `App` 增加 `net_shown: bool`；`main()` 读入 `prefs::net_shown()` 与接口列表/勾选集（持久化缺失时按 `is_default_enabled` 过滤出 en\*），`Snapshot` 字面量补零，`menu::build` 传参。
- `App::refresh()`：标题按 `net_shown` 决定 `status_title` 的 `net` 参数；刷新 `parts.net` 行；`SFM_DEBUG` 输出加网速。
- `App::set_net_shown(bool)`：仿照 `set_mem_style`（改字段 → 持久化 → 同步勾选 → `refresh()`）。
- `App::toggle_net_iface(index: usize)`：翻转到勾/不勾 → `sampler.set_net_ifaces` → `prefs::set_net_ifaces` 落盘 → 翻转该项勾选态 → `refresh()`。
- `MenuHandler`：`toggleNetIface:` 从 `sender` 读回 `tag()`（cast 回 `NSMenuItem`，附 `// SAFETY:`——该 selector 只会由我们的接口项发出，tag 即 `parts.net_ifaces` 下标）后转给 `App::toggle_net_iface`；连同 `setNetShownOn/Off:` 一起在 `extern_methods!` 里提供 Rust 侧包装供 selftest 用。
- `App::quit()`：落盘 `net_shown` 与 `net_ifaces`。
- `selftest()`：按 AGENTS.md 要求同步扩展——打印网速行与「端口范围」各项勾选态；调 `setNetShownOff/On` 验证标题网速段消失/恢复；翻转一个接口项并验证勾选态与 prefs 往返。

## 边界情况已覆盖

- 首帧：sysinfo 新接口差值为 0 + `Instant` 为 `None`，双保险报 0。
- 连续手动刷新：elapsed 下限 0.05s。
- 接口热插拔/VPN 断开：`refresh(true)` 自动移除；勾选集合里残留的旧接口名只是不命中，无害。
- 勾选集合为空：显示 `↓  0K ↑  0K`，不 panic。
- 持久化里存了已不存在的接口：读取时与当前列表求交集展示，集合本身保留（接口可能重现）。
